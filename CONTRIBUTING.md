## Contributing

Thanks for your interest in contributing to Nopalito Scan.

Nopalito Scan is a fork of [FairScan](https://github.com/pynicolas/FairScan). It keeps FairScan's
core promise — fast, private, respectful scanning with no ads, no tracking, no watermarks and no
paywalled core features — and builds on it with an optional private cloud backend. Contributions
should respect that direction:

- Local scanning always works fully without an account or internet connection.
- Cloud features are opt-in and must never gate scanning, exporting, or sharing.
- No ads, no trackers, no watermarks, no artificial limitations.

### Issues

You're very welcome to describe the problems you face when using Nopalito Scan.

When the automatic processing gives a bad result, please share the original image whenever possible.
You can get it from the bug-report section in the "About" screen, which attaches the last captured
image, or send it privately to contact@nopalitoscan.org. Screenshots are usually not helpful to
understand image-processing issues.

The most useful issues focus on the problem rather than on a proposed solution. Understanding the
underlying problem is essential to finding the right solution. A detailed description of the problem
and its context is therefore usually much more valuable than discussing a specific change to the
app.

- ❌ "Please add a button or an option to..."
- ✅ "Here is the problem I face, the context in which it occurs, and why it is problematic..."

### Pull Requests

- Please avoid starting any significant work without discussing it first.
- Small, focused PRs are much easier to review and integrate.
- Every PR must compile cleanly and keep the existing test suite green; add or update tests when
  behavior changes.
- AI-assisted contributions are welcome, but they must be human-reviewed, human-tested, and
  genuinely understood by their author.
- Respect the GPLv3 license: preserve applicable copyright and license notices.

### Project direction

Nopalito Scan is currently maintained by a single person, and product and technical decisions are
centralized. This helps keep the project consistent, and may evolve in the future.

Thanks for your understanding.
